# 天气测试结果契约 v1

Skill 与 MCP 场景使用同一受控天气端点和相同的 `city`。关联标识由各自调用路径内部生成，不要求用户输入，也不参与业务等价比较。两条路径必须返回相同的业务字段：`schema_version`、`city`、`measurement` 和 `provenance`。`run_id` 与 `execution` 仅用于证据关联和区分调用路径。

固定夹具只用于验证 Agent 活动和观测覆盖，不代表真实天气：

| 字段 | 固定值或规则 |
| --- | --- |
| `measurement.temperature_c` | `22.5` |
| `measurement.condition` | `晴（受控测试数据）` |
| `measurement.observed_at` | `2026-09-12T08:00:00.000Z` |
| `provenance.source` | `agentreins-controlled-weather-v1` |
| `provenance.fixture` | `true` |

Skill 路径必须标记 `channel=skill`、`component=agentreins-weather-skill`、`tool_name=query-weather.ps1`；MCP 路径必须标记 `channel=mcp`、`component=agentreins-weather-mcp`、`tool_name=get_controlled_weather`。

请求和响应分别由 `weather-request.schema.json`、`weather-result.schema.json` 定义。服务遇到缺失参数、未知城市、未知路径或鉴权失败时必须返回明确错误，不得改用公网天气服务。
